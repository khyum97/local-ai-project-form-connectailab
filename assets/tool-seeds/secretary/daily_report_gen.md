# daily_report_gen - daily work briefing markdown

Creates a concise daily report from completed work and planned work.

## Config
- `PROJECT_PATH`: project root
- `COMPLETED`: newline or list of completed items
- `PLANNED`: newline or list of planned items
- `BLOCKERS`: newline or list of blockers

## Output
Writes `docs/reports/YYYYMMDD_daily_report.md`.
