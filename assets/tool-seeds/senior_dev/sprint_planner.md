# sprint_planner - sprint plan markdown

Creates a sprint planning document with owner assignment.

## Config
- `PROJECT_PATH`: project root
- `SPRINT_NAME`: sprint name
- `GOALS`: newline/list of goals
- `TEAM`: newline/list of agent or person names

## Output
Writes `docs/sprints/YYYYMMDD_{slug}.md`.
